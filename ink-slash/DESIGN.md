# 먹 한 획 (가제) — 기획 메모

> 마지막 순간에 피하면 시간이 멈춘다. 그 사이 붓으로 한 획을 그어, 그 선 위의 적을 한 번에 벤다.

## 왜 이 기획인가 (그림자 밟기에서 이어진 판단)
- 그림자 밟기에서 확실히 재미있었던 것은 **"아슬아슬 점프"**와 **보는 재미(화풍·연출)**. 장애물·챕터를 늘려도 핵심 조작이 얕아서 밋밋했다
- 사용자가 원하는 것: 스팀 출시 경험 + 사람들이 관심 가질 퀄리티, 스타일리시하고 **타격감 있는 액션**, 3~6개월
- 그래서 "아슬아슬"을 액션의 **저스트 회피**로 옮기고, 수묵화 화풍과 **붓질 = 공격**을 한 덩어리로 묶었다

## 결정 사항 (사용자가 추천안 전부 선택)
- 시점: 탑다운 / 조작: 키보드 이동 + 마우스(베기·획 긋기), 게임패드는 나중 / 반격: 직접 한 획 긋기 / 세계: 먹으로 그린 세계 + 먹 요괴
- 경기장(아레나)형, 한 판 2~3분, 몰려오는 적을 버티며 등급(멋 → 신 → 절)을 올린다

## 시험판 규칙 (`scripts/arena.gd`)
| 요소 | 내용 |
|---|---|
| 이동 | WASD, 초속 270 |
| 베기 | 클릭. 3타 연속(셋째는 크고 묵직). 앞으로 한 발 내딛음 |
| 회피 | Space·Shift·우클릭. 0.17초 대시, 0.26초 무적 |
| 저스트 | 공격이 닿기 0.22초 전 안에 피하면 발동 → 화면이 먹색으로 가라앉고 시간이 거의 멈춤 |
| 한 획 | 멈춘 1.8초 동안 마우스를 누른 채 선을 긋고 떼면, 그 선을 따라 0.16초에 지나가며 선 위 요괴를 전부 벤다. 길이 = 420 + 먹×6 |
| 먹 게이지 | 때리면 +7(셋째 +12), 저스트 +25. 한 획에 쓴 만큼 줄어든다 |
| 체력 | 먹방울 5개. 맞으면 1초 무적 |
| 등급 | 스타일 점수(때림·저스트·한 획 베기 + / 맞으면 −45 / 시간 지나면 감소) → 멋(25) 신(70) 절(130). 점수 배율 1.5 / 2 / 3 |
| 막 | 제 n 막 = 돌진형 2+n/2, 먹 탄형 min(n−1, 3), 방패형(3막부터) min((n−1)/2, 3), 분열형(4막부터) min((n−2)/2, 2). **5막마다 보스** + 돌진형 1+n/5 |

## 적 (`scripts/yokai.gd`)
새 적은 체력·속도만 다른 게 아니라 **한 획을 긋는 방법을 바꾸게** 만든다. 처음 나오면 화면 아래에 짧은 설명이 뜬다.
| 적 | 행동 | 공략 |
|---|---|---|
| 돌진 요괴 | 다가오다 낙관 0.58초 → 직선 돌진(950) → 0.75초 헐떡임. 체력 3 | 돌진이 닿기 직전 저스트 / 헐떡일 때 베기 |
| 먹 탄 요괴 | 거리 340~420 유지하며 맴돌다 낙관 0.5초 → 먹 탄(4막부터 3발). 체력 2 | 먹 탄도 저스트 가능 |
| 방패 요괴 | 앞을 먹 방패로 막고 아이 쪽으로 천천히(초당 2.4라디안) 돈다. 가까우면 낙관 → 방패 밀치기. 체력 3 | 정면 베기는 막힘. **한 획이 방패 정면에 걸리면 획이 그 앞에서 끊긴다** (뒤쪽 요괴는 못 벰, 그 방패만 깨지고 아이는 튕겨 나옴). 그리는 동안 끊기는 곳에 ✕, 뒤쪽 선은 흐린 회색. 옆·뒤로 돌아가거나 **획을 둘러서** 긋기. 셋째 묵직한 베기로 정면에서 방패 깨기(크게 비틀거림). 한 획 미리보기에서 막힐 적은 회색 고리 |
| 분열 요괴 | 크고 느림. 낙관 0.7초 → 느린 돌진. 체력 4 | 일반 공격으로 쓰러뜨리면 **작은 요괴 둘**로 갈라짐(빠르게 튀어 오름, 체력 1). **한 획이면 깔끔** → 한 획을 아껴 둘 이유 |
| 큰 먹도깨비 (보스) | 5막마다. 체력 60. 돌진 → **먹 물결**(퍼지는 고리, 초속 330) → 부채꼴 먹 탄 7발을 돌아가며. **체력 절반 아래면 성남**: 공격 간격 1.3→0.75초, 먹 물결 두 겹(0.6초 간격), 먹 탄 11발 | 먹 물결은 피할 곳이 없어 **저스트로 뚫기**. 한 획은 죽이지 못하고 7 피해 (한 획만으로는 9번) |

## 타격감 연출
- 히트스톱: 베기 0.05초, 셋째 0.09초, 한 획 0.16초 + 벤 수×0.03, 맞음 0.12초, 저스트 0.07초
- 화면 흔들림, 먹 튀김(떨어진 방울은 바닥 자국으로 남음), 반으로 갈라지는 요괴, 마른 붓 자국이 있는 굵은 획, 섬광
- 바닥에 먹 자국이 계속 쌓여 경기장 자체가 점점 수묵화가 된다 (이 게임의 얼굴이 될 수 있음)
- 효과음 합성(`sfx.gd`): 쉭(휘두름), 퍽·탁(타격), 징(저스트), 샥(한 획), 촤악(갈라짐), 칭(낙관), 징(막 시작)
- 글꼴: 큰 글씨는 윈도우 궁서체(붓글씨 느낌). 다른 PC를 위해 출시 전엔 배포 가능한 붓글씨 글꼴을 넣어야 함

## 시험판 판단 기준
**"저스트 → 한 획으로 베는 순간"이 짜릿해서 또 하고 싶은가.** 특히 액션 중에 마우스로 획을 긋는 게 번거롭지 않은지.
번거롭다면 대안: 멈춘 동안 적을 순서대로 클릭하면 그 순서대로 벤다.

## 붓 기술 (`scripts/skills.gd`) — 반복이 질린다는 피드백으로 추가
막을 마칠 때마다 시간이 멈추고 **카드 3장 중 1장**을 고른다(클릭 또는 1·2·3). 같은 기술을 다시 고르면 단계가 오른다. 고른 기술은 왼쪽 위에 도장으로 표시.
목표: 판마다 **한 획을 쓰는 방식 자체가 달라져서** 다른 판이 되게 (로그라이트 빌드).
| 기술 | 효과 (단계마다 세짐) | 최대 |
|---|---|---|
| 번짐 | 획 자리에 먹물이 4/6/8초 남아, 밟은 요괴가 절반 속도 + 0.6초마다 피해 | 3 |
| 겹획 | 멈춘 시간 동안 획을 한 번 더(2단계: 두 번 더). 다음 획은 멈춘 시간이 65% | 2 |
| 꺾음 | 획이 크게 꺾인 자리(50° 이상, 30px 간격으로 다시 찍어 손떨림 무시)마다 먹이 터짐 (반경 75/95/115) | 3 |
| 낙관 | 획 끝에 붉은 도장이 찍히며 터짐 (반경 120/150/180, 보스 3~5 피해) | 3 |
| 잔영 | 0.6초 뒤 먹 그림자가 같은 획을 다시 그음 (방패에 끊기는 규칙도 같음) | 1 |
| 되받아치기 | 저스트 순간 반경 320 안의 적 먹 탄이 가까운 요괴 쪽으로 돌아가 2 피해 | 1 |
| 세필 | 획 길이 +40%/+80%, 베는 폭 −25%/−50% | 2 |
| 굵은 붓 | 베는 폭 +60%/+120%, 획 길이 −20%/−40% | 2 |
| 먹 항아리 | 먹 차는 양 +50%/+100%/+150%, 막마다 먹 +30 | 3 |
| 느린 먹 | 멈춘 시간 +0.6/+1.2초, 저스트 판정 +0.04/+0.08초 | 2 |
| 연환 | 셋째 베기가 먹 칼날을 쏨 (뚫고 지나가며 1/2 피해) | 2 |
| 먹 보충 | 체력 +2 (체력이 깎였을 때만 나옴) | — |
- 기술로 주는 피해(꺾음·낙관·번짐·되받아치기·연환)는 방패를 무시한다
- 한 획에서 파생된 처치(꺾음·낙관·잔영)는 "깔끔한 베기"로 쳐서 분열 요괴가 갈라지지 않는다
