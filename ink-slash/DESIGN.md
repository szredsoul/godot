# 먹 한 획 (가제) — 기획 메모

> 마지막 순간에 피하면 시간이 멈춘다. 그 사이 붓으로 한 획을 그어, 그 선 위의 적을 한 번에 벤다.

## 왜 이 기획인가 (그림자 밟기에서 이어진 판단)
- 그림자 밟기에서 확실히 재미있었던 것은 **"아슬아슬 점프"**와 **보는 재미(화풍·연출)**. 장애물·챕터를 늘려도 핵심 조작이 얕아서 밋밋했다
- 사용자가 원하는 것: 스팀 출시 경험 + 사람들이 관심 가질 퀄리티, 스타일리시하고 **타격감 있는 액션**, 3~6개월
- 그래서 "아슬아슬"을 액션의 **저스트 회피**로 옮기고, 수묵화 화풍과 **붓질 = 공격**을 한 덩어리로 묶었다

## 결정 사항 (사용자가 추천안 전부 선택)
- 시점: 탑다운 / 조작: 키보드 이동 + 마우스(베기·획 긋기), 게임패드는 나중 / 반격: 직접 한 획 긋기 / 세계: 먹으로 그린 세계 + 먹 요괴
- 경기장(아레나)형, 한 판 2~3분, 몰려오는 적을 버티며 등급(멋 → 신 → 절)을 올린다

## 시험판 규칙 (`scripts/arena.gd`)
| 요소 | 내용 |
|---|---|
| 이동 | WASD, 초속 270 |
| 베기 | 클릭. 3타 연속(셋째는 크고 묵직). 앞으로 한 발 내딛음 |
| 회피 | Space·Shift·우클릭. 0.17초 대시, 0.26초 무적 |
| 저스트 | 공격이 닿기 0.22초 전 안에 피하면 발동 → 화면이 먹색으로 가라앉고 시간이 거의 멈춤 |
| 한 획 | 멈춘 1.8초 동안 마우스를 누른 채 선을 긋고 떼면, 그 선을 따라 0.16초에 지나가며 선 위 요괴를 전부 벤다. 길이 = 420 + 먹×6 |
| 먹 게이지 | 때리면 +7(셋째 +12), 저스트 +25. 한 획에 쓴 만큼 줄어든다 |
| 체력 | 먹방울 5개. 맞으면 1초 무적 |
| 등급 | 스타일 점수(때림·저스트·한 획 베기 + / 맞으면 −45 / 시간 지나면 감소) → 멋(25) 신(70) 절(130). 점수 배율 1.5 / 2 / 3 |
| 적 | 돌진형(낙관 0.58초 → 직선 돌진 → 0.75초 헐떡임, 체력 3) / 먹 탄형(거리 두고 맴돌다 낙관 0.5초 → 먹 탄, 4막부터 3발, 체력 2) |
| 막 | 제 n 막 = 돌진형 2+n, 먹 탄형 min(n−1, 4) |

## 타격감 연출
- 히트스톱: 베기 0.05초, 셋째 0.09초, 한 획 0.16초 + 벤 수×0.03, 맞음 0.12초, 저스트 0.07초
- 화면 흔들림, 먹 튀김(떨어진 방울은 바닥 자국으로 남음), 반으로 갈라지는 요괴, 마른 붓 자국이 있는 굵은 획, 섬광
- 바닥에 먹 자국이 계속 쌓여 경기장 자체가 점점 수묵화가 된다 (이 게임의 얼굴이 될 수 있음)
- 효과음 합성(`sfx.gd`): 쉭(휘두름), 퍽·탁(타격), 징(저스트), 샥(한 획), 촤악(갈라짐), 칭(낙관), 징(막 시작)
- 글꼴: 큰 글씨는 윈도우 궁서체(붓글씨 느낌). 다른 PC를 위해 출시 전엔 배포 가능한 붓글씨 글꼴을 넣어야 함

## 시험판 판단 기준
**"저스트 → 한 획으로 베는 순간"이 짜릿해서 또 하고 싶은가.** 특히 액션 중에 마우스로 획을 긋는 게 번거롭지 않은지.
번거롭다면 대안: 멈춘 동안 적을 순서대로 클릭하면 그 순서대로 벤다.
