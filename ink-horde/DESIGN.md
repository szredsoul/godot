# 먹 무리 (가제) — 기획 메모

> 이동만 하면 붓이 알아서 싸운다. 몰려오는 먹 요괴를 쓸어 담고, 레벨업 때마다 무기를 고르며 10분을 버틴다.

## 왜 이 기획인가
- 그림자 밟기·먹 한 획은 "핵심 재미가 정말 재미있나"에서 막혔다 → **인기 있는 게임 시스템을 그대로 가져와** 그 위험을 없애고, 첫 출시 경험에 집중하기로 함 (사용자 결정)
- 장르: **뱀서류** (자동 공격 + 몰려오는 적 + 레벨업 3택 1)
- **선**: 규칙·시스템은 장르 그대로 가져오되, 이름·캐릭터·그림·음악·레벨·겉모습은 대표작을 베끼지 않는다. 주제와 화풍(수묵화, 먹 요괴, 붓·먹·도장 무기)은 우리 것

## 시험판 규칙 (`scripts/game.gd`)
| 요소 | 내용 |
|---|---|
| 조작 | 이동만. WASD·방향키, 또는 마우스 왼쪽 버튼을 누른 채로 커서 쪽으로 (키보드가 우선, 커서 70px 안에서는 천천히, 10px 안이면 멈춤, 가는 곳에 작은 먹 고리). 공격은 무기가 저절로 |
| 한 판 | 10분 버티면 승리. 체력이 0이 되면 끝 |
| 성장 | 쓰러진 요괴가 먹 구슬을 떨어뜨림 → 주우면 경험치 → 레벨업 때 3장 중 1장 (무기·보조 능력). 무기·보조 능력은 각 5칸, 각 최대 5단계 |
| 필요 경험치 | 3 + 레벨×3 + 레벨²×0.3 (초반엔 10초 안팎마다 레벨업) |
| 구슬 | 기본 90px 안이면 끌려온다. 450개가 넘으면 먼 것끼리 합친다 |
| 요괴 나오기 | 화면 바로 바깥 둘레에서. 초당 1.3 + 시간/22 마리, 동시에 최대 380마리, 체력 ×(1 + 시간/200) |
| 정해진 사건 | 1:30·3:30·6:00·7:30 정예(붉은 낙관, 돌진, 쓰러지면 보따리 = 바로 레벨업 + 체력 20) / 2:30 포위(48마리 둥글게) / 7:00 먹 박쥐 떼 / 5:00·9:00 큰 먹도깨비(돌진 + 부채꼴 먹 탄 9발, 쓰러지면 레벨업 2번) |
| 맞음 | 요괴와 닿아 있는 동안 계속 피해(요괴 공격력/초). 보스 먹 탄 12 |

## 무기 (`scripts/upgrades.gd`)
| 무기 | 1단계 | 단계가 오르면 |
|---|---|---|
| 붓 휘두르기 (처음부터) | 바라보는 쪽으로 붓을 크게 휘두름, 0.95초마다 | 3단계부터 앞뒤로, 5단계는 훨씬 넓게 |
| 먹 방울 | 가까운 요괴에게 먹 방울, 0.85초마다 | 3단계 두 발, 4단계 뚫고 지나감, 5단계 세 발 |
| 먹 고리 | 먹 구슬 2개가 몸 주위를 돎 | 구슬 수 2/3/3/4/5, 3단계부터 더 멀리, 5단계 더 빨리 |
| 낙관 도장 | 근처 요괴 무리에 붉은 도장을 쾅, 2.6초마다 | 3단계 두 개, 5단계 세 개, 범위·피해 증가 |
| 한 획 | 16방향 중 요괴가 가장 많은 쪽으로 긴 획(마른 붓 자국)을 그어 한꺼번에 벰 | 더 자주(4.2초 → 2.6초), 길게, 5단계는 훨씬 길고 굵게. 5마리 이상이면 "N연 베기!" |

보조 능력: 진한 먹(피해 +10%), 새 붓털(자주 +8%), 벼루(범위 +10%), 짚신(이동 +8%), 먹 끌림(줍는 거리 +30%), 두루마기(최대 체력 +20%, 다 채움)

## 요괴 (`scripts/horde.gd`)
imp(작은 도깨비) / bat(먹 박쥐, 빠름, 0:45부터) / ogre(뿔 도깨비, 1:10부터) / brute(큰 도깨비, 3:00부터) / elite / boss

## 성능 (수백 마리를 위해)
- 요괴는 노드를 따로 만들지 않고 `Horde` 하나가 배열로 계산·그린다
- 서로 밀어내기는 64px 격자로 가까운 것끼리만
- **요괴 모양은 종류별로 6장(+맞았을 때 흰 모양)을 미리 메시로 만들어 두고 위치만 바꿔 찍는다** → 380마리에서 평균 28fps → 137~155fps
- 화면 밖 요괴·먹 자국은 그리지 않는다, 튄 먹방울은 25%만 자국으로 남긴다, 같은 소리는 0.05초 안에 겹쳐 울리지 않는다
- 요괴끼리 비교는 `is_same()` (Dictionary `==`는 내용 전체를 비교해서 느림)
- `draw_mesh()`는 그림 범위 계산에 위치를 반영하지 않아, 원점에서 멀어지면 요괴가 통째로 사라졌다 → `Horde._ready()`에서 `canvas_item_set_custom_rect()`로 맵 전체를 범위로 지정

## 다음 단계 후보
- 무기 진화(무기 5단계 + 특정 보조 능력 → 상위 무기), 판 끝나고 쓰는 재화와 영구 강화
- 캐릭터 여러 명(시작 무기가 다름), 맵 여러 개(그림 세 폭: 산수화·화조도·민화)
- 상자, 회복 아이템, 자석 같은 줍는 물건

## 보류 (2026-11-27)
- 이유: 재미는 검증된 장르지만, 비슷한 게임이 수천 개라 "왜 이걸 해야 하나"에 답이 없음
- 마지막 상태: 먹 자국이 7~9초 뒤 옅어져 사라지고 최대 350개 (전에는 1분에 2,100개 넘게 쌓여 구슬이 안 보이고 느려졌음). 화면 오른쪽 위에 FPS·가장 느린 프레임·요괴 수·먹 자국 수 표시
- 남은 문제: 시간이 갈수록 평균 FPS가 내려감 (중반 1분 테스트에서 180 → 109, 느린 프레임은 0.4%). 구슬이 계속 쌓이는 것(190개)이 의심됨, 확인하지 않음
- 확인 못 한 것: 10분 한 판 전체 흐름, 균형, 마우스 이동의 실제 손맛, 효과음
