# 그림자 밟기 — 기획 메모

> 인도를 걸으며, 옆 차도를 지나가는 차들의 그림자를 밟지 않고 점프로 넘는다.

## 결정 사항
- 플랫폼: PC (키보드)
- 화풍: 도트 X, 따뜻한 파스텔 톤의 깔끔한 벡터 느낌 (현재는 코드 드로잉, 추후 일러스트로 교체 가능)
- 시점: 탑다운, 자유 이동 (인도 안에서 상하좌우)

## 규칙
| 요소 | 내용 |
|---|---|
| 아웃 | 땅에 있을 때 발이 차 그림자에 닿으면 아웃. 그림자 위에 착지해도 아웃 |
| 점프 | Space, 체공 약 0.75초 |
| 기본 점수 | 그림자 1개 넘을 때마다 100점 + 이동 거리 10px당 1점 |
| 아슬아슬 | 이륙/착지 순간 그림자와 거리 22px 이내 → 점수 x2, 슬로모션 |
| 콤보 | 4초 안에 계속 넘으면 유지. 5콤보마다 배율 +0.5 (최대 x4) |
| 더블 | 한 번 점프로 그림자 2개 이상 → x1.5 |
| 나무 그늘 | 그늘 안에선 차 그림자를 밟아도 안전. 대신 그늘에서 뛴 점프는 점수 없음, 콤보 타이머는 계속 흐름. 나무 간격 600~1100px |

## 난이도 장치
- 차종: 자전거 → 승용차 → 승합차(12초~) → 트럭(30초~) → 버스(55초~)
- 버스는 서서 넘기 거의 불가능 → 마주 달려 넘거나, 그늘에 숨거나
- 트럭/버스 등장 시 화면에 방향 경고
- 해의 위치: 아침·저녁엔 그림자가 길고(인도 전체를 덮음) 한낮엔 짧음. 그늘 크기도 같이 변함
- 시간이 지날수록 차 간격이 좁아짐 (3분에 걸쳐 최대)

## 튜닝 포인트 (scripts/)
- `main.gd`: `NEAR_DIST`, `COMBO_TIME`, `DAY_LEN`, `_pick_kind()`의 등장 시간, `_update_sun()`의 그림자 길이
- `player.gd`: `SPEED`, `JUMP_V`, `GRAVITY`
- `car.gd`: `KINDS` (길이/폭/높이/속도)

## 사운드 (scripts/sfx.gd)
외부 파일 없이 코드로 합성 (시작 시 약 40ms). 이름별로 `sfx.play("이름", 피치, 볼륨dB)`.
발소리, 점프, 착지, 넘기 성공(콤보 높을수록 음 상승), 아슬아슬 차임, 배율 상승 아르페지오, 콤보 끝,
시작, 실패, 트럭/버스 경적, 차 지나가는 소리, 그늘 진입 나뭇잎 소리, 배경 새소리
