# 그림자 밟기 — 기획 메모

> 하굣길, 인도를 걸으며 옆 차도를 지나가는 차들의 그림자를 밟지 않고 집까지 간다.

## 결정 사항
- 플랫폼: PC (키보드)
- 화풍: 도트 X, 따뜻한 파스텔 톤의 깔끔한 느낌 (지금은 코드 드로잉, 나중에 일러스트 에셋으로 바꿀 수 있음)
- 시점: 탑다운, 인도 안에서 자유 이동
- 구름 그림자는 넣지 않음 (넣었다가 사용자 요청으로 뺌)

## 모드
| 모드 | 내용 |
|---|---|
| 하굣길 (그림일기) | 학교 → 우리 집을 6장으로 나눔. 장을 지날 때마다 시간대가 넘어감(오후 3시 → 해질녘 6시 반). 하트 3개. 장을 마치면 다음 장이 열리고, 6장을 다 마치면 다음 계절 하굣길이 열림 (봄 → 여름 → 가을 → 겨울) |
| 도전 모드 | 끝없는 길 (예전 규칙). 한 번 밟으면 끝. 오전 7시~오후 7시, 계절은 무작위 |

## 조작
| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 (걷기 초속 200px) |
| Shift | 달리기 (초속 320px). 공중에서는 방향을 천천히만 바꿀 수 있어 착지 위치 조절이 어려움 |
| Space | 점프. 짧게 누르면 짧게(체공 약 0.42초), 길게 누르면 멀리(약 0.77초) |
| Esc | 쉬기 (계속 / 다시 / 나가기) |
| R | 다시 하기 |

## 규칙
| 요소 | 내용 |
|---|---|
| 밟음 | 땅에 있을 때 발이 차 그림자에 닿으면 하트 -1 (1.6초 무적). 그림자 위 착지도 해당. 골목 차 차체에 부딪혀도 -1. 도전 모드는 바로 끝 |
| 점수 | 그림자 1개 넘을 때마다 100점 × 콤보 배율 |
| 아슬아슬 | 이륙/착지 순간 그림자와 거리 22px 이내 → x2, 슬로모션 |
| 콤보 | 4초 안에 계속 넘으면 유지. 5콤보마다 배율 +0.5 (최대 x4) |
| 더블 | 한 번 점프로 그림자 2개 이상 → x1.5 |
| 나무 그늘 | 그늘 안에선 안전. 그늘에서 뛴 점프는 점수 없음. 겨울엔 잎이 없어 그늘이 작음 |
| 별 3개 | 장의 목표 시각 전 도착 / 한 번도 안 밟기 / 구슬 다 줍기 |
| 도착 점수 | 점프 점수 + 남은 하트×300 + 제시간 도착 500 + 동전×10 |

## 길에서 만나는 것
| 요소 | 내용 |
|---|---|
| 장애물 | 전봇대·버스 표지판(못 넘음), 쓰레기봉투(짧은 점프로 넘음), 세워 둔 자전거(긴 점프로 넘음), 화단(긴 점프, 인도가 좁아짐), 공사 구간(못 넘음, 인도가 좁아짐) |
| 구슬 | 하루 5개. 일부러 차도 쪽 가장자리에 놓임 (별 조건) |
| 동전 | 길 곳곳에. 문방구에서 모자·가방 구입 |
| 행인 | 대부분 마주 옴. 부딪히면 0.4초 멈칫 |
| 강아지 | 가까이 가면 짖어서 0.6초 멈칫 (그림자 앞이면 위험) |
| 친구 | 같이 걷는 친구. 그림자를 알아서 넘고, 밟으면 일기에 적힘 (점수 영향 없음) |
| 신호등 교차로 | 큰길 초록(6.5초) → 노랑(1.6초) → 빨강(6초). 빨간불이면 큰길 차가 46px 간격으로 줄지어 멈춰 그림자가 고정됨(징검다리). 그동안 골목 차가 세로로 횡단보도를 지나감. 교차로에 골목 차가 남아 있으면 큰길 차는 초록불이어도 기다림. 빨간불 동안은 화면 밖에서 새 차가 들어오지 않음(줄이 끝없이 길어지지 않게) |
| 보행 신호 | 보행 신호가 빨간불이면 횡단보도에 들어갈 수 없음(건너는 중이면 마저 건넘). 초록불이 끝나기 2초 전부터 깜빡임 |
| 그늘막 | 횡단보도 양쪽(115px 떨어진 곳)에 초록·흰 줄 그늘막. 인도 위아래 끝과 횡단보도 바로 앞까지 덮어서, 빨간불을 기다리는 동안 멈춘 차 그림자를 피할 수 있음. 거꾸로 놀이에선 시원한 그늘 |
| 버스 정류장 | 다가가면 버스가 와서 5초 정차 → 긴 그림자가 고정 |
| 배달 오토바이 | 아주 빠르고 짧음. 화면 경고 없이 소리로만 |
| 차량 행렬 | 4~6대가 줄지어 옴. 콤보 찬스 |
| 계절 | 봄 꽃잎·그림자 보통 / 여름 매미·그림자 짧음(x0.85) / 가을 낙엽(x1.1) / 겨울 눈·발자국·그림자 김(x1.3)·앙상한 나무 |

## 챕터 구성 (`scripts/game_data.gd`의 `CHAPTERS`)
장마다 **큰길**(짧고 차 많음)과 **골목길**(길고 그늘·강아지·장애물 많음) 중 하나를 고른다.
장을 지날 때마다 시간대가 넘어간다. 장 안에서도 시작~목표 시각 사이로 시간이 흐르고, 늦으면 그 뒤로도 계속 흐른다.

| 장 | 장소 | 시간대 (목표) | 길가 풍경 | 특징 |
|---|---|---|---|---|
| 1 | 학교 앞 | 3:00~3:40 | 학교, 주택 | 자전거·승용차만. 튜토리얼 |
| 2 | 문방구 거리 | 3:40~4:20 | 줄무늬 차양 가게(문방구·분식·슈퍼…), 뽑기 기계 | 신호등 사거리, 행인 많음, 동전 많음 |
| 3 | 공사장 | 4:20~5:00 | 가림막, 고깔, 모래 더미, 굴착기 | **거꾸로 놀이** (새로 깐 아스팔트가 뜨거워 햇빛이 용암) |
| 4 | 시장길 | 5:00~5:30 | 파라솔 노점, 과일 상자 | 노을 시작. 버스 정류장, 트럭, 행인 아주 많음 |
| 5 | 공원 | 5:30~6:00 | 잔디, 산책로, 벤치, 둥근 나무 | 나무 그늘 많음(간격 420~760, 골목 300~560). 차 한산, 트럭 적음. 배달 오토바이는 가끔(14~22초마다) |
| 6 | 우리 동네 | 6:00~6:30 | 주택가, 끝에 우리 집 | 해질녘. 모든 요소. 도착하면 엄마 |

- 시작 표지판(2장부터)과 끝의 "다음 장소 →" 표지판, 하단 진행 막대도 "이 장소 → 다음 장소"로 표시
- 화면 빛: 3시 맑은 오후 → 4시 반 따뜻한 빛 → 5시 반 노을 → 6시 반 분홍·보랏빛 해질녘 (`game.gd`의 `DUSK_KEYS`, `DUSK_COLORS`)
- 그림자 길이: 3시 높이×3.6 → 6시 반 ×4.6 (× 계절 배수). 더 길면 먼 차선 그림자까지 인도를 다 덮어 해질녘 장이 너무 어려워짐
- 계절(회차): 진행 번호 = 계절 × 6 + 장. 계절이 지날수록 차 간격 ×0.92, ×0.85, ×0.8
- 그림일기: 마지막 장은 집과 엄마(칭찬/혼남), 중간 장은 다음 장소 이정표와 친구 그림

## 상상력 연출 (`scripts/imagination.gd`)
"그림자는 ○○이야!" — 아이의 상상대로 인도 위 차 그림자가 다른 세계로 보인다. 차도 위 그림자는 평범하게, 나무 그늘은 안전한 땅으로 남긴다.
| 계절 | 그림자는 | 장식 | 밟으면 |
|---|---|---|---|
| 봄 | 바다 | 물결, 상어 지느러미 | "풍덩! 상어다!" |
| 여름 | 용암 | 부글부글 거품 | "앗 뜨거!" (치익) |
| 가을 | 늪 | 거품, 악어 눈 | "꾸르륵! 악어다!" |
| 겨울 | 얼음 구멍 | 떠다니는 얼음 조각 | "풍덩! 차가워!" |
- 밟으면 아이가 빠지는 연출 + 물보라/불꽃. 아슬아슬하게 넘으면 발밑에서 튐. 가까운 웅덩이에서 가끔 부글 소리.
- 그림 장식은 땅에 고정된 격자 위치 → 그림자가 움직이면 그 아래 세계가 드러나는 느낌.

## 거꾸로 놀이 (3장 공사장, `"rule": "reverse"`)
"오늘은 거꾸로! 햇빛이 용암이야. 그늘로만 다녀!" — 인도 전체가 용암, 차 그림자와 나무 그늘만 안전한 땅.
| 요소 | 내용 |
|---|---|
| 더위 게이지 | 햇빛 위에 서 있으면 1.3초에 가득 → 하트 -1. 그늘에서 1.2초면 다 식음. 공중에선 그대로 |
| 햇빛 착지 | 더위 +30% (점프 연타로 햇빛을 건너는 것 방지) |
| 옮겨 타기 | 한 그늘에서 다른 그늘로 뛰어 옮기면 100점 × 콤보 배율. 그늘 가장자리 14px 안에 착지하면 x2 |
| 차 | 퇴근길 정체 (속도 x0.5). 같은 방향 차선은 아이보다 느리게(x0.4) → 그림자를 끝까지 타고 갈 수 없음 |
| 제한 시간 | 거리 ÷ 걷는 속도 × 1.5 (느린 그림자만 타고 가면 6시를 넘김) |
| 큰길 / 골목길 | 큰길: 느린 버스·트럭 그림자 타기 / 골목길: 나무 그늘 징검다리 (간격 340~620px, 햇빛 구간은 달려야 함) |
- 봇 테스트(그늘에서 기다렸다 옮겨 타기만 하는 단순한 봇): 큰길·골목길 모두 1번 정도 데고 도착. 큰길은 봇이 너무 오래 타고 가서 6시를 넘김.

## 시간과 그림자
- 하굣길: 장마다 정해진 시간대 안에서 흐름. 제한 시간 = 거리 ÷ 걷는 속도 × 2.2 (쉬지 않고 걸으면 장 시간의 절반쯤에 도착, 거꾸로 놀이는 × 1.5)
- 하굣길 그림자 길이: 3시에 높이×3.6 → 6시 반에 ×4.6 (× 계절 배수). 3시에도 승용차 그림자가 인도를 거의 덮음
  - 실제 해 높이대로 하면 3시엔 인도 아래쪽이 늘 안전해서 피하기만 하면 되어 따로 정함
- 도전 모드: 아침·저녁엔 길고 한낮엔 짧음

## 그림일기
도착하면 그날 있었던 일로 일기가 써진다 (버스 그림자를 넘음, 연속 콤보, 아슬아슬 횟수, 강아지, 부딪힘, 친구가 밟은 횟수, 밟은 횟수, 구슬, 도착 시각/혼남).
그림 칸은 도착 시각(하늘색·해 위치), 계절, 엄마 표정(칭찬/혼남)이 달라진다.

## 저장 (`user://save.cfg`)
날짜별 별·최고 점수·클리어, 도전 모드 최고 기록, 동전, 산 물건과 착용 중인 모자·가방.
예전 버전의 `best_score.dat` 기록은 처음 실행할 때 옮겨 온다 (원본은 그대로 둠).

## 튜닝 포인트
- `game.gd`: `NEAR_DIST`, `COMBO_TIME`, `INVULN_TIME`, `QUEUE_GAP`, `_update_sun()`, 제한 시간 배수(2.2)
- `game_data.gd`: `STAGES` (거리, 차 간격, 차종, 나무 간격, 장애물 확률, 행인·강아지 수, 교차로·정류장 위치 등), `SEASONS`, 상점 가격
- `player.gd`: `WALK`, `RUN`, `JUMP_V`, `G_HOLD`, `G_CUT`, `AIR_CONTROL`
- `car.gd`: `KINDS` (길이/폭/높이/속도)
- `crossing.gd`: `DURATION` (신호 길이)

## 사운드 (`scripts/sfx.gd`)
코드로 합성. 발소리, 점프, 착지, 넘기 성공, 아슬아슬, 배율 상승, 콤보 끝, 시작, 실패, 경적, 차 지나가는 소리,
그늘 진입, 새소리, 밟음, 동전, 구슬, 강아지, 부딪힘, 보행 신호, 버스 문, 오토바이, 도착 팡파르, 6시 종, 메뉴 선택, 구매, 여름 매미(반복)
