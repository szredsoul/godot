# 공성전 (가제) — 기획서 v0.3

> **사방에서 성을 에워싼다. 병사들을 어디로, 언제 보낼 것인가.**
> 공성추는 성문을 부수고, 사다리는 성벽을 넘는다. 분대를 옮기는 데는 시간이 걸린다.

작성 2026-11-27 · 상태: 시험판 (폴더 이름 `spin-fort`는 회전 시절 이름 그대로)

## 흐름
1. 오방 결계 (오행 이웃 배치 TD) → 배치 고민이 안 생기고 쉬움
2. 가운데 성 + 방벽 + 사방 + 무너지면 밀려옴 (사용자 제안) + 돌아가는 성벽 → 돌리기가 재미없음
3. 성벽 위 분대 이동 (사용자 제안) → 사용자 12웨이브까지 진행. 평가: **공성전 같은 긴장감이 없다**
4. 사용자 요청으로 지금 구조:
   - 타워·투석기 없앰, **병사로만** 막음
   - 성을 칸으로 나눈 것 없앰. **실제 성처럼 동서남북 성문**, 적은 **공성추로 성문**을 부수고 **사다리로 성벽**을 넘음
   - 성을 더 크게, 성벽·적을 더 단단하게, 전투를 더 길게
   - 화폐는 골드

## 시험판 규칙 (`scripts/game.gd`)
| 요소 | 내용 |
|---|---|
| 성 | 네모난 성 500×300, 성벽은 부서지지 않음. 동서남북 성문(체력 800), 가운데 본성(체력 300, 0이면 패배) |
| 분대 | 최대 10, 분대 체력 120(병사 3명, 다치면 병사가 줄어듦, 0이면 전멸). 싸우지 않으면 초당 4 회복, 웨이브 끝나면 다 회복. 처음: 북·남 궁수, 동·서 창병 |
| 궁수 70 | 사거리 250. 사다리를 오르거나 성벽에 올라온 적 > 성 안의 적 > 성문 앞 > 가까운 적 순으로 노림. 성벽을 걸으면서도 쏨(60%) |
| 창병 70 | 사다리 꼭대기 근처에 서 있으면 사다리를 밀어냄(3초, 오르던 적은 떨어져 체력 절반 잃음). 성벽에 올라온 적·성 안의 적과 싸움 |
| 기름병 80 | 성벽 바로 아래에 끓는 기름(3.2초마다 범위 30). 공성추 2.5배, 큰 도깨비 1.5배 |
| 석공 60 | 가까운 성문 수리(초당 14), 부서진 성문을 35%까지 다시 세움 |
| 이동 | 성벽 왼쪽 클릭 = 성벽 따라 55px/초 (가면서 싸움) / 오른쪽 클릭 = 안마당 지름길 100px/초 + 계단 0.8초씩 (못 싸움) / 안마당 클릭 = 그곳으로 (들어온 적과 싸움). 마우스를 올리면 걸리는 시간 표시 |
| 적 | 졸개(체력 60), 사다리병(50, 성문에서 떨어진 성벽에 사다리를 검), 도끼 도깨비(200, 6웨이브~), 공성추(520, 성문만 때림, 화살 30%), 큰 도깨비(900, 5·10·15). 졸개는 같은 쪽 사다리가 있으면 사다리로, 없으면 성문으로 |
| 사다리 | 한 번에 한 명씩 3초 동안 오름. 꼭대기에 분대가 있으면 성벽 위에서 싸우고, 없으면 성 안으로 넘어옴 |
| 성문 | 부서지면 그쪽 적이 모두 성문으로 몰려 들어옴. 골드로 수리 가능 (체력 6당 1, 부서진 문 +30) |
| 돈 | 시작 180, 웨이브 수입 45 + 5×웨이브, 처치 보상 |
| 웨이브 | 15웨이브. 방향 1(1~2) → 2(3~5) → 3(6~9) → 4(10~), 방향마다 8초씩 늦게. 체력 ×(1 + 0.1(w−1) + 0.01(w−1)²) |
| 긴장감 | 웨이브 시작 북·경보, "○쪽에서 적이 온다!", 사다리마다 ! (지키는 분대 없으면 붉게 빨리), 성문 체력 막대가 맞을 때 번쩍임, 위쪽 경보(○문 위험, ○쪽 사다리 N개!, 성 안에 적!), 성 안에 적이 있으면 가장자리가 붉게 맥박치고 북이 빨라짐, 분대 전멸 알림 |
| 카드 | 두꺼운 문, 발 빠른 훈련, 노련한 병사, 의병, 골드 주머니, 본성 보수, 강궁, 끓는 기름, 갈고리 창(사다리 2배 빨리), 두꺼운 갑옷 |

## 봇 테스트 (지휘 봇 1판, 판마다 차이가 큼)
- 사다리에 창병, 공성추에 기름병, 깎인 문에 석공, 성 안의 적에 창병을 보내는 봇
- 처음 수치: 5웨이브에서 패배, 창병이 근접전에서 모두 전멸 → 큰 도깨비 체력 1400→900·성문 공격 40→25·기름 1.5배, 분대 체력 90→120
- 조정 후: **8웨이브에서 패배**. 웨이브 하나가 50~110초. 봇은 골드를 다 안 쓰고(440까지 쌓임), 분대를 쓸데없이 자주 옮김 → 사람은 더 갈 수 있음
- 남은 문제: 무너질 때는 한 웨이브에 본성이 283 → 0 (여러 문이 동시에 뚫릴 때)

## 판단 기준 (아니면 접음)
1. 사다리·공성추가 동시에 올 때 **어디부터 막을지 고민되고 손에 땀이 나는가**
2. 분대가 늦게 도착하거나 전멸했을 때 **아쉽고 다시 하고 싶은가**
3. 골드를 분대·수리 중 어디에 쓸지 아까운가
